# Student Result Management System

Python aur Tkinter se bana ek GUI application jo student results ko Excel file me manage karta hai.

## Features
* **Tab 1:** Student details aur Subject names add karna
* **Tab 2:** Roll Number se marks input karke Pass/Fail aur Percentage calculate karna
* **Tab 3:** Individual student result search karna

## Requirements & Setup
```bash
pip install openpyxl
python student_app.py
